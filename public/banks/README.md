# Bank logos for the payment page

Drop the official logo file for each bank here and it will automatically
replace the colored fallback badge on `/checkout/prepay`.

Use these exact filenames (any one extension: `.svg`, `.png`, `.webp`, `.jpg`):

| File                | Shows on method                     |
| ------------------- | ----------------------------------- |
| `attijari.svg/png`  | "Simple" and "Attijariwafa Bank"    |
| `populaire.svg/png` | "Banque Populaire — TISSIR"         |
| `cashplus.svg/png`  | "CashPlus / Wafacash"               |

Tips:
- Square-ish logos look best (they render in a 36×36 box, object-fit: contain).
- SVG or a transparent PNG gives the cleanest result.
- Get the official logo from each provider's own website/app or press/brand kit,
  where you're permitted to use it as a "pay with" mark.

Until a file is present, a brand-colored badge (AW / BP / C+) is shown instead.
